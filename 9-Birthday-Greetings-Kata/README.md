Birthday Greetings Kata en TypeScript

Ceci est un exercice de refactoring dédié à l’apprentissage des concepts suivants :

l’inversion de dépendances et l’injection de dépendances

la séparation de la logique métier et de l’infrastructure

l’architecture hexagonale

Le code initial de ce kata est écrit en TypeScript.

Comment démarrer

Pour commencer, tu dois télécharger ce dépôt et installer les dépendances :

yarn

Pour exécuter les tests :

yarn test
